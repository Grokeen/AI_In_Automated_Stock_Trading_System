## 지금 확인된 상태

저장소에는 NAS 상태 점검·운영 설정 도구와 과거 NAS 검증 기록이 있습니다. 매매 애플리케이션, 증권사 어댑터, 시세 수집기, 전략, 주문·체결 기록·복구 기능 및 AI 모델은 미구현입니다. NAS 운영 도구의 과거 테스트 9개는 새 매매 기능 검증으로 계산하지 않습니다. 기존 장비 측정은 [NAS 검증 자료](../reports/nas-validation-20261108.json)에 기록된 시점의 결과이며, 현재 실기 재확인과 매매 애플리케이션 공존 검증을 뜻하지 않습니다.

KIS는 우선 연동 후보로 문서화됐지만 계좌·API 자격증명·모의 서버 연결 여부는 확인되지 않았습니다. API 접근이 없어도 가능한 오프라인·문서·설계 작업은 진행하고, 필요한 실통신만 미검증으로 남깁니다. 실계좌 주문과 NAS 배포는 이번 R1 범위에 없습니다.

확인된 역할은 CD1 감사·프로젝트 관리, CD2 개발, CD3 디자인, CD4 연구, CD5 문서입니다. OPS 배포관리 전담자는 확인되지 않았습니다. 임명 확인은 작업 완료나 독립 검토를 뜻하지 않습니다. R1 제출 상태와 출처는 [팀 현황](TEAM_STATUS.md)에 있습니다. CD1 판정 전에는 자체 검증 완료·검토 대기로 표시합니다.

## 작업·검증·인계 방법

- 파일을 바꾸기 전에 최신 지시, 해당 업무의 입력과 파일 소유 범위를 확인합니다. 다른 역할의 작업 파일, NAS 운영 파일, 기존 `.git` 및 `config.lock`을 수정하지 않습니다.
- 동작·설계의 주장을 근거가 있는 상태로 기록합니다. 실행하지 않은 명령과 확인하지 않은 기능을 통과로 적지 않습니다. 실패·미지원·미검증·대기 조건도 기록합니다.
- 각 역할은 `reports/review_requests/<담당자>_R1.md`에 업무 ID, 변경 파일, 기준 커밋, 커밋 또는 SHA-256, 환경·명령·실제 결과, 남은 문제와 CD1 재현 방법을 씁니다. 필요한 근거 파일은 `reports/verification/<담당자>_R1/`에 둡니다.
- 자체 검증을 마친 뒤 원본 CD1 채팅의 사용자 직접 지시에 근거해 CD1에게 검토를 요청합니다. CD1 판정 전 상태는 ‘자체 검증 완료·CD1 검토 대기’입니다.
- 공통 이력의 이번 라운드 추가분은 CD5가 취합합니다. 각자 자신의 요청서와 검증 근거 작성 책임은 계속 유지합니다.
- 통합·릴리스와 NAS 설치는 해당 범위·담당 조율과 별도 검증을 거쳐야 합니다. 이 안내서만으로 배포·실거래가 승인되지는 않습니다.
