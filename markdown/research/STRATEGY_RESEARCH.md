# RES-02 검증 전략·실험 제안

- 조사일: 2026-11-08 (KST)
- 상태: 재현 가능한 실험 설계 초안. 데이터 다운로드·백테스트 미수행.
- 관련: REQ-05/06/08, T4/T5, RES-02

## 제안 전략: 일봉 이동평균 추세 규칙

처음에는 해석이 간단한 롱온리(매수 또는 현금) 전략 하나로 데이터 처리·신호·비용 반영 파이프라인을 검증한다. 이는 투자 권유나 수익 전략 주장이 아니며, 실전 투입을 전제하지 않는다.

- **입력:** 날짜, 종목코드, 조정 종가, 거래량, 거래일 달력. 값마다 거래소 시각, 데이터 수신 시각, 출처와 조정 기준을 보존한다.
- **신호 예:** 당일 종가 기준 20거래일 단순 이동평균이 60거래일 단순 이동평균을 상향 교차하면 다음 거래일 매수 후보, 하향 교차하면 현금 전환 후보를 낸다. 신호에는 전략 ID/버전, 계산 시각, 입력 종료일, 종목, 방향을 포함한다.
- **실행 가정:** 종가로 계산한 신호는 같은 종가에 체결된 것으로 두지 않는다. 기본 시뮬레이션은 다음 거래일 정규장 시가 또는 사전에 고정한 다음 날 VWAP 대용값으로 체결한다. 주문 모듈/위험 한도는 전략과 분리한다.
- **시장 범위:** 상장폐지 종목을 포함할 수 있는 생존편향 없는 유니버스를 우선한다. 자료가 없어 생존 종목만 쓰면 결과를 편향 가능성 있는 예비 실험으로 표시한다. 신규상장·거래정지·가격제한·휴장일과 액면분할·배당 조정 규칙을 기록한다.

## 비용·체결 가정

비용을 0으로 둔 결과를 기본 성과로 보고하지 않는다. 거래일·시장·계좌에 맞는 매수/매도 수수료, 세금·유관 비용을 각각 입력하며 실제 계좌 요율을 확인하기 전에는 검증되지 않은 가정으로 둔다. 왕복 거래비용 민감도(예: 낮음/기준/높음)를 수치 선정 근거와 함께 돌린다. 슬리피지는 과거 호가·체결 자료가 없으면 고정 basis-point 시나리오로만 근사하고, 그 수치를 실제 체결 추정치로 부르지 않는다. 거래량 대비 주문 규모, 가격제한·거래정지, 미체결·다음 세션 gap을 고려한다.

거래세와 증권사 수수료는 다른 항목이다. KIS 이벤트나 수수료 할인은 사용자의 계좌에 적용된다는 확인이 있을 때만 비용 입력값에 반영한다. 모의 서버가 반환하는 체결 가격·비용을 과거 실제 시장의 체결 근거로 사용하지 않는다.

## 표본 외 검증 절차

1. 분석 전에 종목 유니버스, 조정 가격 정책, 전략 규칙, 비용 시나리오, 지표를 고정해 실험 명세와 버전을 기록한다.
2. 시간 순서로 개발/검증/최종 표본 외 구간을 나눈다. 이동 구간 검증을 쓰더라도 최종 홀드아웃을 반복 의사결정에 재사용하지 않는다.
3. 모든 지표·신호는 그 시점까지 공개된 데이터만 사용한다. 미래 종가로 신호를 만들고 같은 가격에 체결하는 누출, 생존편향, 지표·파라미터 선택 편향을 검사한다.
4. 총·연환산 수익률만 보지 않고 최대 낙폭, 변동성, 회전율, 거래 수, 시장 노출, 비용 전후 성과, 비용 민감도와 매수 후 보유 기준선을 함께 보고한다.
5. 고정 데이터, 전략 코드 버전, 파라미터, 실행 환경, 로그·산출물 해시를 남겨 재현한다. 결과가 데이터 기간·시점 선택에 민감하면 불확실성이 크다고 표시한다.
6. paper 단계는 API 요청·모드 분리·상태 전이·오류 복구를 검증한다. 모의 유동성과 체결 품질은 실전 체결 가능성의 증거가 아니다.

## 데이터 선행 조건과 NAS 배치

가격 데이터 제공자, 과거 일봉의 범위·정정 정책, 종목별 상장폐지 포함 여부, 배당/분할 조정, 사용·저장·재배포 권리는 확보 전까지 미정이다. 개발 시작은 소형 고정 CSV fixture와 합성 예제로 가능하나, 이를 실제 시장 성과로 해석하지 않는다. 백테스트 계산은 별도 PC에서 수행하고 NAS에는 가벼운 paper 실행 및 신호 소비만 우선한다. NAS의 기존 CPU 예산은 실행 가능성의 증명이 아니며 동시 파일공유 부하 측정이 필요하다.

## 사실·가정 구분

- **공식 사실:** KRX 정규 주식 세션은 09:00~15:30 KST이고 휴장일·장외 세션은 별도다. [KRX 거래 안내](https://global.krx.co.kr/contents/GLB/06/0602/0602010201/GLB0602010201T2.jsp)
- **공식 사실:** KIS는 주문/계좌 REST와 기본·분석 시세 REST, 체결·호가 등 WebSocket 범주를 제공한다. [KIS API 요약](https://apiportal.koreainvestment.com/apiservice-summary)
- **제안:** 20/60 일봉 교차 규칙은 파이프라인을 검증하기 위한 투명한 예시일 뿐 최적화·수익성 검증 결과가 아니다.
- **미정:** 종목군, 투자금, 손실 한도, 계좌 비용, 데이터 공급원·사용권, 체결 모델과 실거래 전환 기준은 사용자가 확정하거나 추후 검증해야 한다.

실험 미수행. 성과·비용 수치에 대한 결론은 없다.
